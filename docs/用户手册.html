🚀 宗旨与设计哲学

传统 Markdown 编辑器往往陷入两极分化：要么功能过于简陋，处理表格和长文极其痛苦；要么过于臃肿，打字跟手延迟严重、过度弹窗遮挡创作视线。Lumina Edit Pro 从底层重构了编辑器架构：

  • Local-First 本地优先： 所有文档、图片资源直接存放在本机磁盘，无需云端中转，隐私安全无忧。
  • 零打扰专注原则： 严禁打字时自作主张弹出遮挡视线的浮层；所有强大功能均通过直觉键盘快捷键召唤。
  • 出版级排版审美： 字体、间距、表格、代码块均经过微米级推敲，写出来的文档即刻具备出版物美感。

📐 界面布局与视窗

应用界面由四大核心区域构成：

  1. 集成式标题控制栏（Header）： 包含主菜单（文件/编辑/视图/插入/格式/设置/帮助）、全文即时搜索栏、AI 面板开关及无边框窗口控制。
  2. 左侧工作区与大纲树（SidebarLeft）： 支持本地文件夹目录树浏览、多级大纲折叠展开与点击跳转。
  3. 中央主编辑画卷（Editor）： 支持三种视图模式切换：
    • Alt + 1 所见即所得模式（WYSIWYG）： 沉浸式富文本排版，编辑体验如丝般顺滑。
    • Ctrl + / 源码模式： 纯粹轻快的原生 Markdown 源代码视图。
    • Alt + 3 分屏联动模式： 左右两侧源码与预览联动，适合严谨对照校验。
  4. 底部状态栏（Footer）： 实时呈现文档总字符数、精准汉字/英文词数统计、预估阅读时间及编码格式。

📊 表格大师 (Word 级排版与自适应)

Lumina Edit Pro 彻底打破了 Markdown 表格难排版、死板均分或单字断行的世纪难题：

核心能力 1：智能内容自适应布局 (DeepSeek / OpenAI 风格) 核心自研

表格自动根据单元格内容字数计算最佳宽度：简短的“状态”、“类型”列紧凑收缩，而长篇的“说明”列自动铺展占据 70%~80% 宽度，文字流线舒展，杜绝单个汉字断成一竖列的畸形排版。

核心能力 2：Word 级鼠标拖拽边框调节列宽 媲美 Office

将鼠标移动到任意两列的垂直分割线上（7px 敏捷热区），光标瞬间变为 ↔，并点亮橙色高亮吸附导轨。按住鼠标左键即可左右自由拖拉！

核心能力 3：Excel 级键盘穿梭与列对齐 高产工作流
  • 在单元格内按 Tab：快速跳至右侧单元格；在表格右下角最后一个单元格按下 Tab，自动在末尾新建一行！
  • 按 Shift + Tab：向左回退单元格。
  • 点击工具栏【表格】菜单：提供【当前列对齐：居左 / 居中 / 靠右】以及【自适应内容列宽 (推荐)】一键复位。

🔍 查找与替换 (Ctrl+H)

长篇文档重构术语、修正错别字的终极工具：

  • 按下 Ctrl + H（macOS: Cmd + H），正上方展开极简毛玻璃控制面板。
  • 输入查找词与替换词，右侧实时显示匹配总量与当前焦点（如 1 / 14）。
  • 按 Enter 单步替换下一处；点击 全部替换 瞬间由下至上安全重构整篇文档。
  • 支持精准的 “区分大小写” 与 “全词匹配” 选项，按 Esc 极速退出。

⚡ 全局文档秒开 (Ctrl+P)

面向多文件项目写作的大脑级导航：

  • 无论光标停在何处，轻敲 Ctrl + P（macOS: Cmd + P）瞬间唤出命令盘。
  • 支持拼音首字母与文件名模糊搜索，无需触碰鼠标，用键盘 ↑ ↓ 浏览，按下 Enter 秒级无感切换文档。

🧭 大纲随动雷达 (Scroll-Spy)

在左侧边栏切换至【大纲】标签页，在长文档阅览与编辑时：

  • 当您在正文中向下滚屏阅读时，大纲树会随着视口滚动实时自动高亮当前所在的章节。
  • 当前章节点亮主题色指示条与加粗视觉标识，文章脉络永远清晰。
  • 支持在章节前点击三角图标，折叠或展开下属子标题；大纲顶栏提供 【全部展开 / 全部折叠】 快捷按钮。

🖼️ 图片四角拖拽缩放与对齐

Markdown 图片排版不再僵硬单一：

  • 鼠标拖拽： 鼠标单击正文任意图片，图片右下角与左下角呈现高光圆形拉伸手柄，按住鼠标拖拽即可自由缩放大小。
  • 快速百分比： 悬浮工具栏支持一键切换 25%、50%、75%、100%。
  • 图文对齐： 支持一键将图片设为居左、居中或居右排布。

🎯 专注模式段落聚焦 (Focus Dimming)

专为深度创作打造的沉浸心流状态：

  • 按下 F10 或点击视图菜单【专注模式】，周边所有工具栏与面板隐去。
  • 段落聚焦降噪（iA Writer 级）： 您当前光标所在的书写段落保持 100% 清晰，未激活的上文与下文自动呈现 28% 柔和淡化，消除视觉噪点，将思考完全锁定在眼前的句子里！

💡 现代 Callout 警告块

完全兼容 GitHub / Obsidian 规范的彩色高亮说明块：

ℹ️ NOTE（说明提示）
用于标注常规提示或补充背景信息。语法：> [!NOTE]
💡 TIP（技巧窍门）
用于标注提升效率的实用操作。语法：> [!TIP]
⚠️ WARNING（重要警告）
用于警示潜在风险与注意事项。语法：> [!WARNING]

🪄 行内 AI 助手 (Ctrl+K)

不跳出当前文档、不破坏思路的就地 AI 重塑体验：

  • 选中文档中任意段落或词句，按下 Ctrl + K（macOS: Cmd + K）。
  • 即刻呼出就地 AI 气泡，提供 【润色】、【改写】、【扩写】、【提炼总结】、【生成结构大纲】、【中英翻译】。
  • AI 生成完成后，支持直接按 Enter 就地采纳替换，按 Esc 放弃。

🈳 中英文排版规范化

解决技术方案与中英文混排中的窒息紧贴感：

  • 点击顶部菜单 【格式 -> 中英文排版规范化】；
  • 若当前有选中文本，则自动优化选区；若未选中文本，则一键规范化全文；
  • 系统将自动在汉字与英文字母、阿拉伯数字之间填入规范的微距呼吸空格（例如：用Python编写Markdown，耗时3秒 瞬间规范化为 用 Python 编写 Markdown，耗时 3 秒）。

📤 导出Word、高清长图与多格式交付

满足商务汇报、正式公文、技术白皮书与移动端分享的全场景交付需求：

  • 导出Word · 四大行业权威标准规范： 点击【文件 -> 导出Word】，弹出高颜值主题选择器，支持 4 种出版级专属排版（100% 零依赖，无需安装 Pandoc）：
    • 📘 白皮书风 (Tech Whitepaper)：严格对齐 ISO/IEC 及科技巨头白皮书规范 · Pantone 294C 科技深蓝 · 严谨两端齐平 · 科技三线表 · 专业页眉大纲与动态页码 (第 X 页 / 共 Y 页)；
    • 🏛️ 正式公文 (Formal Enterprise)：严格遵循 GB/T 9704-2012 国家公文格式标准 · 仿宋三号正文 · 黑体/楷体级联标头 · 严格首行缩进 2 字符 · 28 磅公文行距与一字线页码；
    • 📊 商业报告 (Business Report)：国际商业与战略咨询报告标准 · 顶部品牌橙色通栏横幅 · 结构化元数据信息条 · 暖色调阶梯标题 (对标专业咨询与智能体分析报告)；
    • ⚡ 经典极简 (Classic Minimalist)：GitHub / Typora 原生排版标准 · 纯粹白底 · 细线微距 · GitHub 官方灰阶配色 · 极致克制纯净；
  • 导出为长图 (PNG)： 点击【文件 -> 导出为长图 (PNG)】，系统采用 2x Retina 像素级渲染整篇文章，生成超高分辨率长图，发微信、钉钉或知识库极其惊艳。
  • 导出为独立 HTML： 单文件自包含排版样式，脱离任何外部依赖。
  • 打印 / 导出为 PDF： 唤出系统打印管线输出分页矢量 PDF。
  • 标准 Markdown： 保存为通用 .md 文件，与任何主流生态 100% 互通。
