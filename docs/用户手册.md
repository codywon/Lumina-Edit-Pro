## 1. 极速底座与沉浸视窗

### 1.1 300ms 极速秒开（本地离线自包含）
Lumina Edit Pro 采用 **Tauri 2 + Rust + React 19** 现代底层，构建为完全内嵌全量离线静态资产的独立可执行文件（`Lumina-Edit-Pro.exe`）：
* **无网络依赖**：无需预先启动开发端口，断网环境下依然稳定秒开；
* **内存极低**：告别 Electron 动辄数百兆的内存消耗，仅占用数十兆轻量内存。

### 1.2 Codex Desktop 级一体化无边框视窗
* **彻底抹去 Windows 双标题栏**：关闭原生厚重边框，顶栏采用现代无边框平铺风格；
* **顺畅窗口交互**：
  * 按住顶栏任意空白区域单手即可平滑拖动窗口；
  * 双击顶栏空白区域在“最大化”与“还原窗口”之间快速切换；
  * 右上角原生黄金三键：最小化（`─`）、最大化/还原（`□`）、关闭（悬停危险红 `✕`）。

### 1.3 三大视图自由切换
通过工具栏右上角图标或快捷键随时切换：
1. **所见即所得（WYSIWYG，默认）**：排版实时渲染，所写即所见；
2. **纯源码模式（Source，`Ctrl+/`）**：专注于原始 Markdown 语法标记；
3. **双栏分屏（Split，`Alt+3`）**：左侧源码编辑，右侧实时渲染预览，两栏智能**同步滚动**。

## 2. 极致书写与编辑手感

### 2.1 表格 Excel 级键盘流与列宽自适应
在表格中书写与浏览时，排版自然贴合内容：
* **智能防单字折断**：表头标题（`th`）与首列属性参数（`td:first-child`）自动拥有不换行保护与保底宽度，长文说明列自动吸收剩余宽度，**彻底杜绝单字垂直换行的丑陋现象**；
* **横向防溢出平滑滚动**：当表格列数较多时，自动在容器内平滑横向滚动，坚决不挤压破坏文本结构；
* **`Tab` 键穿梭**：光标平滑移动到**下一个单元格**；
* **`Shift + Tab`**：光标向左回退到**上一个单元格**；
* **末尾自动增行**：在表格**最后一个单元格按 `Tab`**，系统自动增添一行新数据，并将光标送入新行首格；
* **表格行高微调**：工具栏提供 `超紧凑 (2px)`、`紧凑常用 (5px)`、`舒适适中 (8px)`、`宽敞松散 (15px)` 黄金档位，点击即刻响应。

### 2.2 零心智图片管理（粘贴 + 拖拽一键落盘）
* **截图粘贴（`Ctrl + V`）**：剪贴板中的图片自动存入当前工作区的 `${filename}.assets/` 相对路径资源目录，并在正文中插入纯净相对路径 `![](xxx.assets/...)`；
* **桌面拖拽（Drag & Drop）**：直接从 Windows 桌面或资源管理器拖入任意图片（PNG/JPG/WEBP 等），光标处即刻自动落盘并插入，**绝对杜绝几兆的 Base64 乱码污染 Markdown 文档**。

### 2.3 物理级打字机模式（Typewriter Mode）
在【设置 -> 编辑体验】中开启后：
* 随着持续敲击与换行，视口会自动将当前活跃行平滑锁定在屏幕垂直约 **45% 黄金平视高度**；
* 无论书写 500 字还是 10 万字，眼睛和颈椎始终保持平视，告别低头看屏幕底部的疲劳。

### 2.4 中英文双核字数统计与真实阅读时长
底栏实时解析文档：
* **精准算法**：每个中文字符独立计词，英文按单词空格分词，真实展示 `总字符数 / 总词数`；
* **科学阅读时长**：基于 300 词/分钟阅读速度，动态给出预估耗时（如 `约 5 分钟阅读`）。

## 3. 现代文档排版与大纲体系

### 3.1 GitHub / Obsidian 标准 Callout 警告卡片
文档中只需按通用语法书写引用块，即可自动升级为彩色高质感卡片：

```markdown
> [!NOTE]
> 这是常规定位与背景说明信息。

> [!TIP]
> 这是一个提高效率的实用技巧。

> [!IMPORTANT]
> 关键核心逻辑，需要重点审阅。

> [!WARNING]
> 这是一个潜在注意事项，请留心。

> [!CAUTION]
> 危险操作警告，不可撤销。
```

* **高质感色彩体系**：
  * `NOTE`：海洋蓝（`#0969da`），带圆形信息图标；
  * `TIP`：翡翠绿（`#1a7f37`），带灵感灯泡图标；
  * `IMPORTANT`：深邃紫（`#8250df`），带聚焦标记图标；
  * `WARNING`：暖琥珀（`#9a6700`），带三角警告图标；
  * `CAUTION`：警示绯红（`#cf222e`），带八角警示图标；
* **暗色模式自动护眼调优**；保存导出时依然是纯净 GFM 语法，无任何平台锁定。

### 3.2 目录大纲与层级折叠（Section Folding）
展开左侧【大纲】面板：
* 自动提取文档内全部 H1~H6 标题树；
* 拥有子章节的标题自动配备折叠微箭头（`Chevron`），可一键收拢/展开所属章节；
* 顶部提供 **【全部展开 / 全部折叠】** 快速切换按钮；
* 点击大纲任意节点，主编辑区平滑滚动跳转。

## 4. 高效生产力：Ctrl+P 文档命令盘

对标 VS Code 与 Obsidian 的神级操作体验：

* **呼出快捷键**：全局按下 **`Ctrl + P`**（Mac: `Cmd + P`），或点击菜单【文件 -> 快速打开...】；
* **极简毛玻璃浮层**：在屏幕正上方轻盈展开；
* **实时模糊拼音/字母匹配**：无需记住文件全名，输入首字母或路径关键字即可瞬间定位；
* **全键盘流**：
  * `↑` `↓`：上下移动选择目标；
  * `Enter`：直接打开并加载对应文档；
  * `Esc`：秒退命令盘回到正文。

## 5. Cursor 级 AI 就地重塑助手（Ctrl+K）

改变传统“复制文字 -> 粘贴到侧栏聊天框 -> 等待 -> 复制结果 -> 粘贴回正文”的割裂繁琐交互，提供**纯粹克制、就地直接修改（In-Place Rewrite）**：

### 5.1 纯净无干扰交互原则
* **双击与拖拽零打扰**：笔记本触控板双击选词、按住拖拽选择多行文字时，**系统完全保持静默，绝不自动弹窗遮挡视线**；
* **唯一主动唤起**：只有当您真正需要 AI 介入时，选中文本按下 **`Ctrl + K`**（Mac: `Cmd + K`），才在选区下方优雅呼出行内 AI 浮动工作台。

### 5.2 交互流程
1. **唤起**：选中文本（或光标停在任意行），按 **`Ctrl + K`**；
2. **输入指令**：
   * 可自由输入：“用通俗口语重写这段”、“提炼为 3 点总结”、“翻译为纯正英文”、“将这些数据转为 3 列表格”；
   * 或点击内置快捷胶囊：`✨ 润色文采`、`📝 提炼要点`、`🌐 翻译为英文`、`📋 转为表格`、`🔍 纠正错别字`；
3. **原地采纳**：
   * 生成后显示预览与 Diff；
   * 按 **`Enter`（或点击“替换选区”）**：在正文中原地完成替换！
   * 还支持【插入下方】、【一键复制】与 `Esc` 放弃。

## 6. 全局 AI 侧边栏与资产管线

### 6.1 精致合理的默认尺寸与字号解耦
* **适中宽度**：AI 侧栏默认采用 **390px** 黄金宽度（可自由拖拽缩放至 300px~600px，双击分界线一秒还原 390px）；
* **排版彻底解耦**：无论正文编辑器字体调到多大（24px、30px），AI 侧栏均保持专属的 **14px 黄金字阶（`.prose-ai`）**，绝不产生大字折行破坏视觉；
* **专属字号微调面板**：右上角配备 `[A- 14 A+]` 控件，支持 12px~18px 自由调节并持久记忆。

### 6.2 Mac 风格代码卡片
AI 回答中包含的代码块自动套用终端卡片样式：
* 顶部标明语言类别（如 `PYTHON` / `RUST`）；
* 右上角提供 **一键复制代码** 按钮，点击伴有“已复制”绿色动效；
* 数据表格自带圆角斑马纹与防撑破横向平滑滚动条。

## 7. 安全与自动保存策略

### 7.1 编辑后按需自动保存（Smart Auto-Save）
* **默认关闭（`autoSave: false`）**：给创作者充分的掌控感；
* **真改动才保存**：开启后，只有当文档正文**确实发生了修改**，且键盘**停止输入超过 3 秒**（时长可在设置中调至 3s、5s、10s、30s）后，才会执行静默落盘；
* **0 冗余写入**：如果仅是滚屏、点击、未修改内容，系统绝对不执行任何写盘动作。
