# Lumina Edit Pro

> **做全球体验最好、性能最强、最懂创作心流的 Local-First AI Markdown 桌面编辑器。**  
> 📖 **完整用户手册**：详见 [docs/USER_MANUAL.md](docs/USER_MANUAL.md)（或 [docs/用户手册.md](docs/用户手册.md)）

**核心杀手级体验**
- ⚡ **300ms 极速冷启动**：基于 Tauri 2 + Rust + React 19，全离线单文件可执行程序，永不依赖开发端口。
- 🖥️ **Codex Desktop 沉浸式视窗**：彻底抹去 Windows 双标题栏，无边框一体化窗口，全顶栏平滑拖动与双击最大化。
- 📊 **表格 Excel 级键盘流**：`Tab` / `Shift+Tab` 顺畅穿梭单元格，末尾 `Tab` 自动增行，光标永不离键盘。
- 🖼️ **零心智图片管理**：外部图片拖拽（Drag & Drop）或截图 `Ctrl+V` 直接自动落盘到 `.assets` 目录并插入相对路径，坚决杜绝 Base64 乱码。
- ⌨️ **真实打字机模式**：光标自动锁定在垂直 45% 黄金线，长文写作平视不伤颈椎。
- 💡 **现代 Callout 警告块**：原生兼容 GitHub / Obsidian 语法（`> [!NOTE]` / `> [!TIP]` / `> [!WARNING]` / `> [!IMPORTANT]` / `> [!CAUTION]`），高质感彩色边条卡片。
- 🚀 **`Ctrl + P` 文档秒开命令盘**：屏幕顶部极简毛玻璃浮层，全键盘模糊拼音匹配，秒速切换工作区文档。
- 🪄 **`Ctrl + K` 行内 AI 原地重塑**：Cursor 级就地润色、翻译、提炼、转表格，原地一键回车采纳，写作心流毫不割裂。
- 📐 **排版与字号彻底解耦**：AI 侧栏拥有专属 14px 黄金字阶（支持 `[A- 14 A+]` 微调），主画布字体放大再多也永不破坏侧栏规整排版。
- 🛡️ **智能按需保存**：默认关闭自动保存，开启后仅在内容真正发生改动且键盘停止 3 秒后才静默写盘，0 冗余 IO。

**主要能力**
- OpenAI 兼容配置：自定义 `baseUrl` / `apiKey`
- 模型管理：本地默认仅 `gpt-5`，支持远程刷新或本地维护
- AI 能力中心：模型、模板、记忆与 API 配置一体化
- 模板体系：内置 + 自定义模板，支持标签、Slash 指令、默认模板
- 会话体验：流式输出、停止与重试、错误详情、Markdown 渲染
- 上下文与记忆：可配置上下文预算（默认 200k / 阈值 80%），自动摘要，长短记忆分离
- 历史与检索：历史对话 grep 检索、工作区 Markdown 文档检索（可开关）
- 编辑器内联 AI：选区/光标动作、差异预览、插入/替换/追加
- UI 细节：AI 侧栏可拉伸，字体与排版适配，正文排版更接近主流 Markdown 编辑器

**默认上下文策略（最佳实践）**
- 有选区：优先选区
- 无选区：检索相关片段
- 达到阈值：触发摘要压缩
- 摘要输入包含 head/tail 限制以控制成本（仍保留原文，可继续检索）

**导出与打印**
- HTML 导出：先渲染 Markdown 再导出，内置排版样式
- PDF 导出：调用浏览器打印，只输出正文（隐藏侧栏/工具栏）
- 代码块：Mac 风格窗口样式，自动换行；打印/导出时隐藏复制等按钮
- 打印提示：如需背景色，请在浏览器打印对话框开启“背景图形/背景颜色”

**本地运行**
1. 安装依赖：`npm install`
2. 启动开发：`npm run dev`

**配置说明**
- 运行后在“AI 能力中心”填写 `baseUrl` 与 `apiKey`
- 模型列表可手动维护或通过“刷新模型”获取
- 上下文预算可全局设置，也可按模型覆盖
- 无需配置 `.env` 即可使用 OpenAI 兼容配置
